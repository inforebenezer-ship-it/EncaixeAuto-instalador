# EncaixeAuto — instaladores

Instaladores do **EncaixeAuto** (encaixe automático de moldes) e do **Moldes** (modelagem e graduação).
Este repositório só guarda as versões publicadas; o código fica em outro lugar.

**Para instalar:** abra [Releases](../../releases/latest), baixe `EncaixeAuto-Setup-<versão>.exe` e
rode. O Windows pode avisar "O Windows protegeu o computador" (o instalador não tem assinatura digital):
clique em **Mais informações › Executar assim mesmo**.

Depois de instalado, o programa avisa sozinho quando sai uma versão nova (cada versão traz um
`versao.json` com o número da versão, o SHA-256 do instalador e o que mudou).
